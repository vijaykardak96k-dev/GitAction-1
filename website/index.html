GitHub Actions Workflow Steps Breakdown
1
Checkout & Setup
Clone the repository and configure the Docker Buildx environment for multi-platform builds.
2
Build Docker Image
Build the Docker image from the project Dockerfile and tag it with the commit SHA and latest.
3
Push to Docker Hub
Authenticate and push the tagged image to Docker Hub as a versioned backup of the build.
4
SSH into EC2
Securely connect to the AWS EC2 instance using an SSH key stored as a GitHub Actions secret.
5
Pull & Restart
Pull the latest image from Docker Hub and restart the container to serve the updated application.
6
Health Check
Verify the container is running and the application is reachable before marking the pipeline green.
